# WhereOnEarth

A WorldGuessr-style geography guessing game: you see a Street View panorama, place a guess
on a world map, and score points by how close you are. Built with Next.js, TypeScript and
MongoDB as a learning project.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install     # install dependencies (first time, or after package.json changes)
npm run dev     # start the development server at http://localhost:3000
```

Check the backend is running: open http://localhost:3000/api/health
